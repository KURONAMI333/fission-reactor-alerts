# Screenshots / demo checklist — Fission Reactor Alerts

Everything this mod shows a player is **one chat message** (plus the same line in
the server log). There is no GUI, no block, no item — so the shot list is short
by design.

## Candidate screenshots (pick 1–2)

1. **The alert itself** — chat showing the damage message with position,
   damage % and temperature, ideally with a formed fission reactor visible
   behind the chat. This is the single honest screenshot of the product.
2. **Team vs proximity (optional second shot)** — same chat line received by a
   team member on a claimed site, or by a nearby player on an unclaimed one.
   Only worth a second shot if it reads differently at a glance.

## How to stage it

- Build and form a minimum fission reactor (3×3×4 casing, one fuel assembly +
  control rod), then drive damage up — easiest with a deliberately starved or
  overheating reactor in a throwaway world.
- For the claim path: claim the reactor's chunks with FTB Chunks before the
  damage starts, on a second account or with a teammate, to show the team
  message variant.
- Keep the shot on the vanilla/FTB default look — the alert is a plain system
  chat line; nothing else on screen is ours.

## Do NOT screenshot

- Config screens, GUIs, recipe viewers — this mod has none.
- Any "mod list" or metadata screen presented as feature evidence.
- Anything implying client-side HUD/overlay — there is none.
