# Forge 1.20.1 API evidence

Observed against Mekanism Generators 10.4.16.80, CurseForge file 6552914, and Mekanism core 10.4.16.80, CurseForge file 6552911. CurseForge marks the Generators file as a Release for Minecraft 1.20.1 and Forge/NeoForge. The source tag is `v1.20.1-10.4.16.80`.

- Official source: `src/generators/java/mekanism/generators/common/content/fission/FissionReactorMultiblockData.java` at `https://github.com/mekanism/Mekanism/tree/v1.20.1-10.4.16.80`.
- Downloaded official source SHA-256: `aa20335d5ca8a3fc5428f0cf57a23ea4a3887b19872b88726bb58b34dfeb7f9b`.
- `javap -p -s` on the official Forge 1.20.1 Generators JAR showed `public boolean tick(Level)` with descriptor `(Lnet/minecraft/world/level/Level;)Z` and `public double reactorDamage` with descriptor `D`.
- `javap -p -c` showed `handleDamage(Level)` called at bytecode offset 65, before the method returns at offset 190.
- Mekanism core's `MultiblockData` exposes public `UUID inventoryID`, `getMinPos()`, `getMaxPos()`, and `isFormed()`.
- Forge 47.4.13 Mojmap artifact showed `ServerPlayer(MinecraftServer, ServerLevel, GameProfile)`, `PlayerList.placeNewPlayer(Connection, ServerPlayer)`, and the Forge GameTest annotation packages under `net.minecraftforge.gametest`. The entrypoint uses Forge’s standard `@Mod` no-argument constructor. No 1.21 `CommonListenerCookie` or NeoForge annotation/import is present.
- Forge 1.20.1 FTB mapped artifacts showed `FTBChunksAPI.api().getManager()`, `ClaimedChunkManager.getChunk(ChunkDimPos)`, `ChunkTeamData.getTeam()`, and `Team.getOnlineMembers()`. The FTB-typed bridge is a separate class, loaded reflectively only after `ModList` confirms both optional mods; the outer fallback class references no FTB API types.
- The published `ftb-chunks-forge:2001.3.8`, `ftb-teams-forge:2001.3.2`, and `ftb-library-forge:2001.2.13` POM/module metadata and their actual JAR `META-INF/mods.toml` files were inspected. The metadata requires Architectury `[9.1.12,)`; this cell pins the Forge 1.20.1 artifact `architectury-forge:9.2.14` and declares it in both `modCompileOnly` and conditional `modRuntimeOnly`. LegacyForge documents that `mod*` configurations are non-transitive, so it cannot be omitted. Architectury’s official Maven (`https://maven.architectury.dev/`) and Maven Central are explicit in the project repositories so this dependency and the JUnit dependencies resolve without relying on plugin-injected repositories. FTB Chunks embeds MixinExtras 0.4.1 through Forge JarJar and requires `ftblibrary` and `ftbteams`, also explicit dependencies.
- `FissionReactorMultiblockData#tick(Level):boolean` is Mekanism’s own method and has no Minecraft/SRG mapping entry. `@Mixin(remap=false)` and `@Inject(remap=false)` are set because Mixin 0.8.5 specifies that these suppress obfuscation mapping lookup for non-obfuscated targets/methods. The Minecraft `Level` class path in the method descriptor is unchanged: `net/minecraft/world/level/Level.class` exists in the Forge 47.4.13 mapped, injected, binpatched, and SRG artifacts. Sources: [Mixin `@Mixin` Javadoc](https://github.com/SpongePowered/Mixin/blob/0.8.5/src/main/java/org/spongepowered/asm/mixin/Mixin.java), [Mixin `@Inject` Javadoc](https://github.com/SpongePowered/Mixin/blob/0.8.5/src/main/java/org/spongepowered/asm/mixin/injection/Inject.java), [ModDevGradle LegacyForge remapping docs](https://raw.githubusercontent.com/neoforged/ModDevGradle/main/LEGACY.md#remapping-mod-dependencies).

The method descriptor is the actual injection target; it is not inferred from the NeoForge 1.21.1 filename or a package-name substitution.
